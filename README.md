# 患者购药情况分析看板

面向 DTP 药房随访团队的单页看板：输入「销售明细 / 随访任务 / 患者用药周期」三类 Excel，
自动算出**每位患者下次应购药日期**、判定**应回未回 / 已回 / 未到期 / 已逾期**、
归类**未购药原因**，并生成**可分品种一键复制的周报**。

纯前端、零后端：**所有数据只在操作者本机浏览器内处理，不会上传到任何服务器。**

## 在线使用

打开：`index.html`（部署版）或 `index.single.html`（单文件离线版，可下载后双击打开）

操作说明见 `使用手册.html`（或 `manual.html`）。

## 本地文件说明

| 文件 | 说明 |
|---|---|
| `index.html` | 部署版页面（依赖同目录 `vendor/`） |
| `index.single.html` | 单文件离线版（库已内联，可单独分发） |
| `使用手册.html` / `manual.html` | 使用手册（内容相同） |
| `vendor/` | Excel 解析库（SheetJS / ExcelJS） |

## 主要功能

- **应购日预测**：`应购日 = 最后一次购药日 + 用药周期 × 购药数量`（可切换算法 / 开关「按数量」）
- **品种标准周期**：泰瑞沙 30、利普卓 28、英飞凡 21、沃瑞沙 21、凡舒卓 28、荃科得 28；达必妥按支（14 天/支，患者级）
- **状态与原因**：四类状态 + 五类未购药原因（可人工覆盖、分类可维护）
- **筛选**：品种 / 医院 / 药房 / 随访人 / 时间段 / 关键词；命中项置顶高亮
- **周报**：分品种小结 + 「复制全部品种」一键复制；周期支持上周/本周/下周与自定义区间
- **数据不重导**：本地自动保存；下次只导新一周即可，重复记录自动去重
- **导出**：名单 Excel、随访回传表、脱敏快照（可外发）

## 技术

- 构建：`python build.py`（生成 `index.html`）、`python build.py --single`（生成 `index.single.html`）
- 源码：`mapping.js`（品种与原因判定）、`pipeline.js`（三表解析归一）、`app.js`（计算/渲染/导出/持久化）、`index.template.html`
- 测试：`tests/` 下的 Node 脚本（`node tests/_test_xxx.js`）
